# Music ENEXYZ for Android

Нативное Android-приложение с фиолетовым оформлением ENEXYZ.

## Что реализовано в первой сборке

- выбор одного или нескольких аудиофайлов через системный файловый выбор Android;
- очередь треков и переключение между ними;
- воспроизведение, пауза и перемотка;
- фоновое воспроизведение через Media3 MediaSessionService;
- системное уведомление и медиакнопки Android;
- работа без Root и без VPN для локальных файлов.

## Ограничение переноса

В загруженном Windows EXE обнаружен Electron runtime, но исходный файл resources/app.asar отсутствует. Поэтому из одного EXE нельзя достоверно восстановить исходные экраны, авторизацию, сетевой API, каталог или потоковый сервис оригинального приложения.

Эта ветка содержит самостоятельную Android-основу музыкального плеера, а не заявление о полном переносе Windows-клиента. Для переноса облачных функций и точного совпадения с Windows-версией нужны исходники Electron (app.asar или папка проекта) и сведения о backend/API.

## Сборка APK

В GitHub откройте Actions → Build Music ENEXYZ Android APK. После успешного запуска скачайте артефакт Music-ENEXYZ-Android-APK; внутри будет app-debug.apk.

Workflow запускается при push в ветку music-enexyz-android и вручную через workflow_dispatch.
