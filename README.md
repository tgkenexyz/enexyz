# FLY OPTIMIZER — Android без root

Приложение для диагностики производительности Android и безопасной настройки трёх масштабов анимации через Shizuku (ADB, без root).

- **Без Shizuku:** температура (статус), RAM, число логических ядер CPU и быстрый переход к настройкам Android.
- **С Shizuku:** профили 0.5× и 0× для системной анимации, снимок исходных значений перед первым изменением.
- **Откат:** восстановление именно сохранённых исходных значений всех трёх настроек, включая отсутствие значения. Запись выполняется по списку разрешённых ключей. Системные пакеты и службы не отключаются.

**Важно:** без root нельзя поднять частоты процессора или RAM или менять пределы защиты от перегрева; ускорение анимаций не ускоряет процессор. Кнопка отката касается только значений, записанных самим FLY Optimizer, а не всех пользовательских настроек телефона. Не удаляйте приложение до отката: снимок хранится локально.

## Сборка APK через GitHub

Actions → **Build Android APK** → **Run workflow** (или дождитесь автоматической сборки после коммита). Скачайте артефакт `FLY-Optimizer-debug-APK`, распакуйте ZIP и установите `app-debug.apk`. Это отладочная сборка, её код открыт в репозитории.

## Как пользоваться без root

1. Установите APK. Кнопки статистики и настроек уже доступны.
2. Для системных анимаций установите [Shizuku](https://shizuku.rikka.app/download/) и активируйте через «Беспроводная отладка» (Android 11+) или ADB с ПК (более старые Android).
3. В FLY Optimizer нажмите «Подключить Shizuku» и подтвердите разрешение.
4. Нажмите «0.5×» или «0×». Приложение сначала запомнит 3 исходных значения.
5. Нажмите «BACK / ВЕРНУТЬ КАК БЫЛО» — значения будут восстановлены. Shizuku должен быть активен и при откате.

Shizuku, запущенный через ADB, обычно требует повторной активации после перезагрузки. На разных прошивках часть команд может быть недоступна. При неудаче приложение сообщает об ошибке и не удаляет резервную копию.

## Технические детали

Java, Android SDK, Gradle 8.13 + Android Gradle Plugin 8.13.2, Shizuku API 13.1.5 и выделенная Shizuku UserService по AIDL. Целевые изменения ограничены ключами `window_animation_scale`, `transition_animation_scale`, `animator_duration_scale`. Все вызовы выполняются по кнопке пользователя, без постоянной фоновой службы. Нет INTERNET-разрешения и аналитики.
