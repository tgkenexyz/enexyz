# FLY Optimizer v0.2 — без root

Экспериментальный Android APK для диагностики подвисаний в играх на Android 16 / HyperOS 3 без root. Скриншот диагностики пользователя показывает **Xiaomi 24069PC21G / peridot / SM8635 (POCO F6)**, а не POCO F6 Pro. Устройство с модифицированной прошивкой может подменять строковые идентификаторы; приоритет — реальная диагностика на телефоне. Это инструмент для **проверяемой настройки**, а не разгон.

## Что делает приложение

- Показывает фактические системные строки Build.MODEL, Build.DEVICE, Build.DISPLAY и чип, режимы частоты экрана, RAM, место в памяти, температуру **батареи** и Android Thermal Status.
- Показывает список запускаемых приложений и позволяет выбрать пакет игры.
- **Shizuku без root:** сохраняет исходную настройку `device_config game_overlay` только выбранной игры и тестирует `mode=2,fps=120` либо `mode=2,fps=60` (Android Game Mode, только в режиме «Производительность», если вмешательство поддерживается).
- **Shizuku без root:** профили системных анимаций 0.5× / 0×; это не разгон и не увеличение FPS игры.
- **BACK / Восстановить исходное:** возвращает ранее прочитанное значение `game_overlay` (включая отсутствие настройки) и значения трёх анимаций. Откат каждого набора подтверждается повторным чтением. Неудавшиеся снимки остаются сохранёнными.

**Ограничения:** POCO F6 (peridot) и POCO F6 Pro (vermeer) имеют экраны до 120 Гц. Счётчик 144–165 FPS может показывать частоту рендеринга, но не частоту матрицы. На портированной прошивке Android Game Mode может не поддерживаться/игнорироваться игрой. Приложение не поднимает частоты CPU, GPU, RAM, не меняет напряжение или thermal service, не запускает постоянные службы, не отключает пакеты Android. Приложение не может гарантировать отсутствие фризов.

## Как собрать APK в GitHub

Откройте **Actions → Build Android APK** в этом репозитории. После запуска workflow и **успешной** сборки внизу страницы запуска появится артефакт `FLY-Optimizer-APK` → внутри `app-debug.apk`. GitHub Actions также запускается после push в `main`. Это неподписанный релизным ключом debug APK (для локальной установки применяется debug-подпись Android SDK), а не магазинная публикация.

## Настройка Shizuku без root

1. Установите [Shizuku](https://shizuku.rikka.app/download/).
2. В настройках разработчика Android 11+ включите беспроводную отладку и запустите Shizuku по инструкции приложения. Иногда требуется повторное подключение после перезагрузки.
3. Запустите FLY Optimizer и нажмите «Подключить Shizuku», разрешите доступ.
4. Выберите игру. Сначала проверьте **120 FPS**, а если профиль работает, но есть фризы — **60 FPS** для сравнения.
5. Для действительного применения game_overlay игре может требоваться Android Game Mode «Производительность», перезапуск игры, и игра не должна самостоятельно переопределять вмешательство.
6. Чтобы вернуть исходные настройки, нажмите **BACK / ВОССТАНОВИТЬ ИСХОДНОЕ** при активном Shizuku.

**Важно:** локальные снимки хранятся в SharedPreferences приложения. Не удаляйте данные приложения, не переустанавливайте APK с несовместимой подписью, не очищайте его хранилище до отката. BACK **не** откатывает саму прошивку или пользовательские настройки вне FLY Optimizer.

## Диагностика через ADB (команды ничего не изменяют)

```bash
adb shell getprop ro.product.model
adb shell getprop ro.product.device
adb shell getprop ro.build.display.id
adb shell settings get system peak_refresh_rate
adb shell settings get system min_refresh_rate
adb shell dumpsys thermalservice
adb shell device_config get game_overlay com.example.game
```

Замените `com.example.game` на реальный идентификатор игры. Прошивка `3.0.304.0.WNPRUXM.C07` относится по маркировке к ветке POCO F6 (peridot); данные на скриншоте — `24069PC21G / peridot / SM8635`, которые совпадают с POCO F6. Приложение показывает фактические системные свойства, а не пытается определить устройство по надписи F6 Pro в переписке.

## Реальные причины микрофризов

Нестабильное время кадра, температурное снижение частот, компиляция шейдеров, недостаток свободного места, конкурирующие приложения, поведение GPU-драйвера или самой игры. Если Game Mode не помогает, потребуется сравнение кадров и температуры в одинаковой игровой сцене. «Ускорение RAM» через приложение без root не существует.
